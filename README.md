
# Indian House Price Prediction

## About the Project
This project uses Machine Learning to estimate house prices across 10 Indian cities based on property details such as location, property type, BHK, area, furnishing status, and distance to nearby facilities.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Random Forest Regression
- Streamlit
- Joblib

## Features
- Select from 10 Indian cities.
- Enter property details using an interactive form.
- Get an estimated house price in Indian Rupees (lakhs).

## Model Performance
- R² Score: 0.7837
- Mean Absolute Error (MAE): approximately ₹33.36 lakhs
